# 한 끼 예산 식권

예산과 끼니 수로 한 끼에 쓸 수 있는 돈을 계산하고, 그 안에서 먹을 수 있는 메뉴를 추천하는 웹앱입니다.

## 계산 방식

- 총 끼니 = 기간(주) × 주당 등교일 × 하루 끼니 수
- 이번 끼니 예산 = 남은 예산 ÷ 남은 끼니
- 먹은 금액을 기록할 때마다 다시 계산합니다. 아낀 만큼 다음 끼니 예산이 늘고, 초과하면 줄어듭니다.

예: 주 5일 × 하루 2끼 = 10끼, 예산 100,000원 → 한 끼 10,000원

## 사용법

`index.html` 하나로 동작합니다. 브라우저에서 열거나 GitHub Pages로 배포하세요.
기록은 브라우저의 localStorage에 저장됩니다.

메뉴 가격은 서울 대학가 기준 대략적인 시세이며, `index.html`의 `MENUS` 배열에서 수정할 수 있습니다.
